土著内网验证码识别 - 便携版（Windows 64 位）
================================================

本程序在局域网内提供验证码识别服务。安装在一台常开的 Windows 电脑上，
局域网内其他设备通过浏览器扩展自动识别并填写业务系统的验证码。

本便携版已内置 Python 运行时与全部依赖，目标电脑不需要预先安装
Python、pip 或任何第三方组件。


一、安装与启动
------------------------------------------------

1. 将 OCR-portable.zip 完整解压到本地磁盘目录，例如 D:\OCR-portable。
   解压路径建议使用纯英文且不含空格。

2. 双击根目录下的 OCR-Panel.bat。

3. 首次运行时 Windows 会弹出用户账户控制对话框，选择“是”以授予权限。
   若出现 SmartScreen 提示，选择“更多信息”后点击“仍要运行”。

4. 首次初始化需要 10 至 30 秒。完成后控制面板会显示服务状态与连接信息，
   同时根目录会自动生成带图标的快捷方式“OCR 控制面板”。

5. 此后日常使用双击“OCR 控制面板”快捷方式即可。


二、控制面板
------------------------------------------------

控制面板提供以下功能：

  - 服务状态：绿色表示运行中，黄色表示启动中，红色表示已停止。
  - 连接信息：完整显示安装地址、服务器地址与 API token，每项均可单独复制，
    也可使用“一键复制全部”生成完整说明。
  - 启动服务 / 停止服务 / 重启服务。
  - 开机自启：默认关闭，开启后登录 Windows 时自动在后台启动服务。
  - 检查更新：比对当前版本与线上版本，发现新版本后自动下载并升级。
  - 日志：实时显示服务运行日志。

关闭控制面板不会停止服务。如需停止服务，请使用面板中的“停止服务”按钮，
或双击 launchers\Stop-OCR.bat。


三、局域网设备接入
------------------------------------------------

局域网内其他设备接入步骤如下：

1. 在浏览器中安装 Tampermonkey（油猴）扩展。

2. 打开控制面板显示的安装地址，格式为：

       http://<本机局域网IP>:1205/userscript.user.js

3. 点击“安装”。该地址已内置服务器地址与 token，无需手动配置。

4. 打开业务系统网站，验证码将自动识别并填入。

其他设备无需安装 Python，也无需下载本便携版。


四、连接信息
------------------------------------------------

双击 launchers\Show-OCR-Info.bat 可查看服务器地址、API token 与安装地址，
并将完整信息复制到剪贴板。

  - 推荐向局域网设备分发“安装地址”，该地址已包含必要参数。
  - API token 等同于访问凭证，仅可在局域网内部分发。
  - 请勿将 token 或 server\config.json 上传至任何公开位置。


五、日常操作
------------------------------------------------

  - 启动服务：控制面板中的“启动服务”。
  - 停止服务：控制面板中的“停止服务”。
  - 重启服务：修改配置后使用“重启服务”使配置生效。
  - 查看连接信息：控制面板的“连接信息”区域。
  - 查看日志：控制面板下方的日志区域，日志文件为 server.log 与 server.err.log。
  - 修改端口或客户端白名单：编辑 server\config.json，然后重启服务。


六、升级
------------------------------------------------

在线升级：

  控制面板中的“检查更新”，或双击 launchers\Update-OCR.bat。

  升级过程会保留 server\config.json 与 python\ 目录，更新前自动备份至
  backup-时间戳\ 目录，完成后自动重启服务。

离线升级：

  在可联网的电脑下载最新代码包，复制到本机后运行：

       powershell -ExecutionPolicy Bypass -File tools\update_ocr.ps1 -SourceZip "C:\path\main.zip"

升级不会更改 API token。如手动更换了 token，局域网设备需重新打开安装地址
完成一次安装。


七、故障处理
------------------------------------------------

服务无法启动，提示缺少 Python 依赖：

  便携版已内置依赖，出现此提示通常说明当前使用的是源码包而非便携包。
  请从 GitHub Release 页面下载 OCR-portable.zip，解压后重新运行。
  若使用源码包，可运行 launchers\Start-OCR.bat 自动安装依赖。

快捷方式无法打开，提示找不到脚本文件：

  快捷方式内记录的是绝对路径。目录移动或跨电脑复制后，双击一次
  OCR-Panel.bat 即可按当前路径重新生成快捷方式。

局域网设备无法访问安装地址：

  确认设备与本机处于同一局域网；确认 Windows 防火墙允许 1205 端口；
  确认 server\config.json 中的 allowed_clients 包含对应网段。

提示 token 无效：

  在局域网设备上重新打开安装地址并安装一次，服务端会自动注入当前 token。

更换电脑或 IP 地址：

  在控制面板中点击“首次配置/修复”。如有需要，修改 server\config.json
  中的 work_lan_ip。


八、目录说明
------------------------------------------------

  OCR-Panel.bat        控制面板入口
  README-FIRST.txt     本说明文件
  launchers\           启动、停止、更新等快捷脚本
  server\              服务端程序与配置（含 config.json）
  userscript\          浏览器扩展脚本源文件
  tools\               部署、构建与测试工具
  docs\                完整文档
  assets\              图标资源
  python\              内置 Python 运行时与依赖


九、防火墙与端口
------------------------------------------------

默认监听端口为 1205。首次配置时会自动创建对应的 Windows 防火墙规则。
如手工调整了端口，请在防火墙中放行新端口，并同步修改 server\config.json。

完整文档请参阅 docs\ 目录。
